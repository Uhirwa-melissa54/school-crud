# School Management CRUD App

This is a Node.js and Express.js-based CRUD (Create, Read, Update, Delete) application designed for managing school data. It supports both:

- **With database**: MongoDB (Mongoose)
- **Without database**: In-memory JavaScript object (temporary data storage)

## 🛠 Technologies Used

- Node.js
- Express.js
- MongoDB with Mongoose (for persistent storage)
